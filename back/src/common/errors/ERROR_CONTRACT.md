# API Error Contract

All API errors follow this payload shape:

- statusCode: number
- code: string
- message: string
- details: object | undefined
- path: string
- timestamp: ISO date string

Example:

{
"statusCode": 401,
"code": "AUTH_INVALID_CREDENTIALS",
"message": "Invalid email or password",
"details": null,
"path": "/auth/login",
"timestamp": "2026-04-24T20:00:00.000Z"
}
